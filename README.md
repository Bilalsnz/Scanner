# ZEC SIGNAL\n\nA mobile-first market-intelligence scanner for indexed DEX pairs whose quote-token symbol is ZEC.\n\n## Features\n- Searches DEX Screener for ZEC, ZCAT, and MASK, then filters pairs to quoteToken.symbol === ZEC.\n- Displays provider-reported price, 24h change, liquidity, volume, and buy/sell counts.\n- Calculates a transparent activity heuristic using volume/liquidity, swap-count imbalance, price movement, and liquidity bands.\n- Provides per-market reasoning and provider links.\n- No wallet, trade execution, fabricated live fallback, or claim that quote-token backing is verified.\n\n## Deploy\nDeploy this repository to Vercel. The api/markets.js serverless function proxies the DEX Screener search endpoint to avoid relying on browser CORS. index.html calls the same-origin proxy.\n\n## Data limitations\nSource: https://docs.dexscreener.com/api/reference. Pair search is not exhaustive; only results returned for configured queries are scanned. A ZEC quote symbol does not prove native ZEC, 1:1 backing, redeemability, or a trusted issuer. Data can be stale, incomplete, manipulated, or unavailable. The score is a research heuristic, not a prediction, safety rating, or buy recommendation. Buy/sell counts are transactions, not unique traders or net capital flow. No historical anomaly baseline is claimed.\n\nThe example layout contains synthetic values, explicitly labelled as illustrative. Do not use them for trading.\n\n## Endpoint\nGET /api/markets?q=ZEC\nOnly GET is accepted. The query is length-limited and passed to the documented DEX Screener pair-search endpoint. Provider errors are surfaced to the UI; the app does not silently substitute demo values.\n\n## License\nMIT\n
